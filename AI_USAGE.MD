# AI Usage

I use Claude (Anthropic) as a tool in this project.

## What Claude does
- Writes most of the code based on my instructions
- Explains new concepts, code and research findings
- Points out errors and contradictions (e.g. in the data documentation)
- Helps me put my notes and documentation into writing

## What is my own
- Topic, research question and personal motivation
- The structure and order of the work (what to do first and what comes next)
- The approach (e.g. going through all 131 columns first, exploring each sample separately)
- Choice of data, sources and columns, and the reasons for it
- Running and checking every step, and the interpretation of the results

## How I check the work
I run all code myself, compare the results with the data and the documentation, and only keep what I understand.
